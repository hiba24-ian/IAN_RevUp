# IAN RevUp — Automotive Website Concept

A multi-page automotive website concept with image assets.

## Pages
- `index.html` — home page
- `cars.html` — cars page
- `reviews.html` — reviews page
- `specialdeals.html` — special deals page

## Assets
The `assets/images/` directory contains the images used by the pages.

## Run locally
Open `index.html` in a browser. Keep the `assets/` directory alongside the HTML files.

## Project scope
A static website design exercise. Vehicle listings, reviews, and offers are sample content, not live inventory or verified commercial offers.
